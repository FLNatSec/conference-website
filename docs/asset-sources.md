## Regenerating the map geometry

```bash
# Download the two source files (not committed) to any folder outside the repo, then:
npm run geo:build -- <path>/cb_2024_us_state_500k.zip <path>/ne_10m_admin_0_countries.zip
```

This rewrites `content/florida/projection.ts` (small; safe for client components) and `content/florida/geometry.ts` (path data; server components only).
